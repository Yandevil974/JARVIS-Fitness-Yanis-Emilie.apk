# Yanis Fitness Evolution 1.3.0 — étapes 1 à 7, avant l’IA

[Télécharger l’APK complet](Yanis-Fitness-Evolution-1.3.0.apk?raw=true)

**Nouvelle application séparée, autorisée après la perte de la signature précédente.** Elle ne remplace pas automatiquement la 1.0.6, la 1.1.0 ou la 1.2.0. Le nom reste exactement **Yanis Fitness Evolution** ; l’identifiant Android est `app.yanis.fitness.evolution`. Pour reconnaître cette installation parmi d’anciennes icônes portant le même nom, vérifier **V 1.3.0** dans l’application ou la version dans les informations Android.

## 1. Garder tes données

1. Dans l’application contenant tes données les plus récentes : **Mon profil → Données & sauvegardes → Exporter la sauvegarde JSON**. Conserver le fichier dans un endroit privé.
2. Télécharger puis installer cet APK. Si Android demande d’autoriser l’installation depuis le navigateur utilisé, n’accorder cette autorisation que si le fichier provient bien du lien de ce dépôt.
3. Ouvrir la **nouvelle 1.3.0**, puis **Mon profil → Données & sauvegardes → Choisir une sauvegarde → Sauvegarder puis importer**.
4. Vérifier les profils **Yanis ET Émilie** : séances, programmes, mesures, photos, bilans, et les décisions/brouillons s’ils existent dans l’export. Fermer puis rouvrir pour vérifier la conservation.
5. **Ne désinstaller aucune ancienne application et ne pas effacer ses données.** Une sauvegarde ancienne ou celle du dépôt ne remplace pas ton export à jour.

Si Android refuse, demande une suppression ou affiche une alerte inattendue, ne désinstalle rien et ne désactive pas aveuglément les protections : conserver le fichier et transmettre le message exact. Android 8 ou supérieur requis.

## 2. Ce qui est inclus

Les fonctions de l’APK complet fourni sont conservées, avec les correctifs du chronomètre et les sept étapes :

1. **Suivi et rappels** : échéances, reports, actions ; poids et mensurations distincts ; lire ne signifie pas réaliser.
2. **Voix et dictée** : diagnostics, texte modifiable avant envoi volontaire, annulation, priorité des chronos. Pas de micro automatique.
3. **JARVIS porte-parole facultatif** : point court fondé sur tes données, raisons, lecture/répétition, report, réglages par profil.
4. **Rendez-vous guidés** : avant/après une vraie séance, bilan hebdomadaire et mensurations ; brouillon, relecture, confirmation ; photos facultatives.
5. **Adaptations expliquées** : hausse, maintien, allègement ou données insuffisantes, selon des réalisations comparables et les ressentis déclarés. Pas de diagnostic médical ni de test maximal imposé.
6. **Décisions et suivi** : accepter/refuser/reporter, choix de la cible et confirmation, historique séparé, suivi des séries réellement effectuées. Un refus ou report ne modifie pas le programme.
7. **Notifications Android application fermée** : consentement par profil et par installation, programmation/annulation, dédoublonnage et contenu discret.

**L’IA conversationnelle générale n’est pas incluse.** JARVIS conserve le fonctionnement local à règles et ses fonctions vocales. Les services de dictée/voix Android peuvent utiliser Internet selon les services installés ; le hors-ligne vocal n’est pas garanti.

## 3. Activer et essayer les notifications

1. Sur **Accueil**, ouvrir **Rappels Android**. Le bouton de **Mon profil → Matériel & préférences** renvoie aussi au suivi Android.
2. Choisir **Autoriser les notifications Android**, puis **Activer pour ce profil**. Accorder l’autorisation Android ne suffit pas à activer les deux profils.
3. Choisir **Envoyer une notification de test**. Cela ne valide aucune séance ni aucun bilan.
4. Refaire l’activation dans l’autre profil seulement si tu le souhaites. Vérifier l’état et le nombre de rappels en attente.
5. Pour tester application fermée, prévoir une vraie séance à un horaire proche, laisser le temps à la programmation de se synchroniser, quitter normalement l’application puis verrouiller l’écran. Les séances sont rappelées **environ 30 minutes avant** ; les bilans à **18 h**. Une séance déjà commencée, terminée ou partielle n’est plus rappelée.
6. Vérifier qu’un report/désactivation met à jour la programmation. Pour tester un redémarrage, déverrouiller le téléphone après le démarrage.

Les notifications ne montrent ni nom, ni poids, ni douleur, ni détail de séance. Ouvrir le rappel n’enregistre aucune réalisation. Si une alerte manque, ouvrir **Réglages Android**, vérifier l’autorisation, le canal de notification et les restrictions d’énergie propres au téléphone.

**Limites Android :** les alarmes sont volontairement inexactes ; Doze, l’économie de batterie ou le fabricant peuvent les retarder. Après **Forcer l’arrêt**, il faut rouvrir l’application. Une notification trop tardive pour une séance n’est pas affichée. Aucun horaire exact ni réception sur tout appareil n’est garanti par les tests simulés.

## 4. Petit parcours de vérification sur téléphone

- Les 11 rubriques et les onglets de chaque profil sont accessibles.
- Importer, fermer/rouvrir, comparer les deux profils ; ne pas créer de fausses mesures pour tester dans tes données réelles.
- Dicter un message : le texte apparaît sans être envoyé. Corriger, annuler puis envoyer volontairement. Tester aussi refus/réautorisation du micro.
- Écouter le point JARVIS, l’arrêter, changer de profil ; vérifier le son et le français installé.
- Lancer un chrono, pause/reprise/fin, valider sans écran blanc. Vérifier les annonces de séance.
- Garder un brouillon de rendez-vous, le reprendre, puis confirmer seulement des valeurs réelles.
- Consulter une adaptation ; vérifier ses raisons avant une éventuelle décision. Si les données sont insuffisantes, l’absence de proposition chiffrée est normale.
- Tester les notifications ci-dessus, écran verrouillé et après redémarrage.

L’APK est construit et signé ; les contrôles automatisés sont décrits dans [le rapport d’étape 7](../evolution/notifications/README.md). **Aucun essai sur téléphone ou émulateur n’a été effectué ici.** En cas de problème, transmettre le modèle du téléphone, la version Android, l’action et le message affiché, sans publier de sauvegarde personnelle.

## 5. Conserver la signature de cette nouvelle application

Le fichier **`Yanis-Fitness-Evolution-SAUVEGARDE-PRIVEE.zip`** est remis séparément dans la conversation. **Ce n’est pas l’APK à installer, ni ta sauvegarde sportive.** Il contient les secrets nécessaires aux prochaines mises à jour ; le ZIP lui-même n’est pas chiffré. Ne jamais le publier sur GitHub.

Télécharger ce ZIP et en conserver **deux copies privées**, par exemple sur le téléphone et dans un espace cloud privé ou une clé USB. Une copie chiffrée existe dans le dépôt, mais elle reste inutilisable sans le secret contenu dans l’archive privée. Le téléchargement effectif doit être confirmé ; afficher le fichier dans la conversation ne suffit pas.
