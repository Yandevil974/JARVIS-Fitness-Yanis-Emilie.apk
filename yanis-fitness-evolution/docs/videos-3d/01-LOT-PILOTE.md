## PILOTE 1 — Exercice avec haltères

- **Nom exact** : Curl haltères (`id : curl-halteres`)
- **Consignes réelles** : « Coudes fixes le long du corps, pas d’élan. »
  Tip : « Coudes fixes, monte sans à-coups. » — 2×12, tempo 2011, repos 45 s.
- **Position de départ** : debout, un haltère hexagonal dans chaque main,
  bras tendus le long du corps, paumes vers l’avant.
- **Trajectoire** : flexion simultanée des deux coudes, haltères montant vers
  les épaules, coudes fixes ; pause haute ; descente contrôlée.
- **Phases** : concentrique = montée (flexion) · excentrique = descente lente.
- **Muscles** : principal **biceps** (rouge) · secondaires avant-bras (orange
  léger).
- **Matériel** : 2 haltères hexagonaux.
- **Angles** : vue de 3/4 face, plan moyen (mi-cuisses → tête), caméra fixe.
- **Image de référence** : `ref-curl-halteres.jpg` (+ poster déjà copié dans
  `public/videos/posters/curl-halteres.jpg`).
- **Prompt Arena** : voir `02-PROMPTS-ARENA.md`, prompt n° 1.
- **Critères de validation** : 2 bras, 2 haltères, coudes immobiles, montée
  sans élan du buste, biceps rouges visibles, boucle propre début/fin.

## PILOTE 2 — Exercice à la poulie (PRIORITÉ Yanis : triceps)

- **Nom exact** : Extension triceps à la poulie
  (`id : extension-triceps-a-la-poulie`)
- **Consignes réelles** : « Coudes collés au corps, extension complète. »
  Tip : « Coudes fixes, verrouille les bras en bas. » — 2×12, tempo 2011,
  repos 45 s.
- **Position de départ** : debout face à la poulie haute, buste droit, barre
  droite en prise pronation à hauteur poitrine, coudes fléchis collés au corps.
- **Trajectoire** : extension des coudes vers le bas jusqu’aux bras tendus
  (sans verrouillage brutal), coudes fixes ; remontée contrôlée à la
  poitrine. Le câble reste dans l’axe.
- **Phases** : concentrique = poussée vers le bas · excentrique = remontée.
- **Muscles** : principal **triceps** (rouge) · secondaires épaules
  antérieures (orange léger).
- **Matériel** : station à poulie haute + barre droite.
- **Angles** : vue latérale 3/4 (profil lisible des bras + trajectoire du
  câble), plan moyen, caméra fixe.
- **Image de référence** : `ref-triceps-pushdown.jpg` (+ poster déjà copié
  dans `public/videos/posters/extension-triceps-a-la-poulie.jpg`).
- **Prompt Arena** : voir `02-PROMPTS-ARENA.md`, prompt n° 2.
- **Critères de validation** : coudes collés et immobiles, barre descendue
  jusqu’aux cuisses, câble cohérent avec la poulie, triceps rouges, pas de
  buste qui s’écrase, boucle propre.

## PILOTE 3 — Exercice jambes (+ barre)

- **Nom exact** : Back squat (`id : back-squat`)
- **Consignes réelles** : « Charge modérée à lourde mais maîtrisée :
  l’objectif reste le galbe, pas la performance en squat. »
  Tip : « Poitrine haute, genoux dans l’axe des pieds. » — 4×8-10,
  tempo 3011, repos 135 s.
- **Position de départ** : debout, barre chargée sur le haut du dos, pieds
  largeur épaules, poitrine haute.
- **Trajectoire** : flexion hanches + genoux jusqu’au parallèle (cuisses
  horizontales), genoux dans l’axe des pieds, talons au sol ; remontée en
  poussant le sol, dos neutre.
- **Phases** : excentrique = descente (~3 s) · concentrique = remontée puissante.
- **Muscles** : principaux **quadriceps** (rouge) + fessiers (orange) ·
  secondaires ischios/adducteurs (reflet léger).
- **Matériel** : barre olympique chargée (disques noirs).
- **Angles** : vue latérale 3/4, plan large (pieds → tête + barre entière),
  caméra fixe.
- **Image de référence** : `ref-back-squat.jpg` (+ poster déjà copié dans
  `public/videos/posters/back-squat.jpg`).
- **Prompt Arena** : voir `02-PROMPTS-ARENA.md`, prompt n° 3.
- **Critères de validation** : barre stable sur le dos, profondeur au
  parallèle, genoux alignés, 2 jambes symétriques, quads/fessiers colorés,
  boucle propre.
