## Réserves de référence

- **Relevés inclinés** : les deux jambes sont presque confondues sur la vue de profil, une seule chaussure est bien nette. La consigne écrite doit primer.
- **Crunch swiss ball** : position conforme, ballon sous le milieu du dos.
- **Jackknife** : ballon sous les tibias, mains au sol, hanches hautes. La première tentative plaçait le ballon sous le ventre, elle a été supprimée.
- **Wood chop** : quatre tentatives ont été nécessaires. Les versions 1 et 2 faisaient passer le câble à travers le corps ou repartir derrière, elles sont supprimées. La version retenue (v3) est une **vue de profil pure**, colonne à poulie, poulie haute et empilement de poids dans le même plan que l'athlète, un seul câble tendu en ligne droite jusqu'à la poignée, entièrement visible. C'est ce cadrage qui doit servir de référence : ne pas revenir aux vues de trois quarts, où le générateur casse le câble.
- Aucune de ces quatre images n'a encore été transformée en vidéo : les réserves seront affichées dans la fiche, comme pour les lots précédents.

## 5 et 6. Les deux circuits

Ces deux fiches sont des **enchaînements de trois mouvements** sur 45 secondes par tour, pas un geste unique.

- **Circuit gainage** = planche + gainage latéral + bird dog.
- **Circuit abdominaux** = crunch + relevés de jambes + gainage.

Ils ne nécessitent pas de nouvelle génération : les mouvements qui les composent doivent être filmés séparément (planche, relevés allongés, crunch, gainage latéral, bird dog), puis assemblés en un montage. Je ne fabrique pas ce montage avant d'avoir les clips unitaires, sinon le résultat montrerait des gestes manquants.

Le bird dog et le gainage latéral appartiennent aussi au module « gainage profond » : la même vidéo servira aux deux endroits, comme le veut la règle de réutilisation.

1. Planche et relevés allongés (images déjà prêtes, lot 94).
2. Relevés inclinés, crunch swiss ball, jackknife, wood chop (ce document).
3. Gainage latéral et bird dog (à préparer avec le module gainage profond).
4. Montage des deux circuits.

Une fois ces clips reçus, les **15 fiches d'abdominaux seront couvertes** et le module pourra être déclaré terminé.
