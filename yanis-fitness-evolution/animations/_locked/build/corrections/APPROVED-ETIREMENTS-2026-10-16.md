## Références consultées

- ACE Fitness, « Are Your Clients Doing Enough Flexibility Training? » — étirement
  statique tenu ~30 s, tension légère jamais douloureuse, expiration en entrant
  dans l'étirement, routine de 5 à 10 min sur les grands groupes musculaires :
  <https://www.acefitness.org/resources/pros/expert-articles/5632/are-your-clients-doing-enough-flexibility-training/>
- Mayo Clinic, « A guide to basic stretches » — tenir ~30 s, 2 à 4 répétitions par
  côté, 2 à 3 jours/semaine ; quadriceps : talon tiré vers la fesse, genoux joints,
  abdos gainés ; fléchisseurs de hanche : genou au sol, dos droit, poids vers
  l'avant : <https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/stretching/art-20546848>
- Doorway pec stretch (repères de placement) : coude et épaule à ~90°, un pied
  devant, tête et thorax neutres, abdos engagés, poids déplacé vers l'avant
  (« step through »), 30-45 s : <https://www.acropt.com/blog/2017/8/17/postural-stretches>
  et <https://www.motra.com/exercises/doorwayChestStretch> (épaules basses et en
  arrière, inclinaison venant du thorax, respiration ample, pas de cambrure).

## Cues appliqués par visuel (charte athlète/décor E1 inchangée)

| Visuel | Cues de posture |
|---|---|
| Encadrement de porte (pec) | avant-bras/appui à hauteur d'épaule, coude ~90°, pas sous l'épaule (sinon inefficace), thorax incliné vers l'avant, appui = montant de marbre de la terrasse (décor E1 interdit les murs intérieurs) |
| Bras tendu contre le mur (pec) | bras tendu à hauteur d'épaule, paume au montant, rotation du tronc opposée à l'appui, épaule basse |
| Position de l'enfant (dos, lom) | genoux au sol, hanches vers les talons, bras tendus devant, front vers le sol, respiration dans le dos |
| Suspension à la barre (dos) | prise légèrement plus large que les épaules, coudes tendus, épaules étirées, corps gainé immobile |
| Torsion allongée genoux (dos, lom) | épaules au sol, genoux groupés basculés d'un côté, regard opposé |
| Mains croisées derrière le dos (epA) | coudes tendus, mains croisées derrière le dos, poitrine ouverte, épaules basses |
| Bras contre la poitrine (epL) | bras horizontal à hauteur de poitrine, main opposée en crochet, traction vers le corps, épaule basse |
| Bras devant main tirée (epP) | bras tendu devant, poignet fléchi, main tirée vers soi, coude verrouillé |
| Bras tendu derrière (bic) | bras tendus vers l'arrière, paumes vers le haut, thorax ouvert |
| Coude au-dessus de la tête (tri) | coude fléchi derrière la tête, main opposée tire le coude, colonne longue |
| Main dans le dos (tri) | bras le long du dos, main montant entre les omoplates, étirement assisté léger |
| Fléchisseurs (avb) | genou au sol (serviette), dos droit, bassin basculé vers l'avant, poids vers la jambe avant |
| Extenseurs (avb) | debout près d'un support, talon vers la fesse, genoux joints, abdos gainés |
| Cobra (abs) | mains sous les épaules, pubis au sol, poitrine ouverte, épaules basses, amplitude douce |
| Pigeon assis (fes) | cheville sur genou opposé, dos droit, hanches vers l'arrière, étirement du piriforme |
| Talon vers la fesse debout (qua) | appui mural, talon saisi, genoux joints, bassin neutre |
| Allongé sur le côté (qua) | sur le flanc, talon du dessus vers la fesse, genoux alignés |
| Flexion avant jambes tendues (isc) | hanches charnières, dos long, mains vers les tibias, genoux souples |
| Une jambe tendue une pliée (isc) | assis, une jambe tendue, inclinaison du tronc vers le pied, dos long |
| Grenouille plantes jointes (add) | assis, plantes jointes, talons vers le bassin, dos droit, coudes sur les cuisses |
| Étirement contre le mur (mol) | pied arrière à plat, jambe arrière tendue, mains au mur, talon ancré |
| Mollet en escalier (mol) | avant-pied sur la marche, talon descendu sous le niveau, appui tenu |
