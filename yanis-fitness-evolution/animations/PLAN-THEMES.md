# Plan de production THÉMATIQUE — reconstruction des animations

Généré par `scripts/build-plan-themes.py` depuis `animations/inventaire.json`.

- Mannequin anatomique 3D très musclé, **corps blanc argenté mat**.

- **Visage entièrement noir mat**, sans aucun trait. Casquette blanche.

- Short noir, baskets blanches. Muscles travaillés **doré jaune-orangé**.

- Décor unique : **terrasse bord de mer** (pierre claire, mer, palmiers, mur blanc bas).

- Exception : **piscine intérieure** pour les exercices aquatiques (vue mi-air / mi-eau).

- **Tapis de sport noir** pour tous les exercices au sol.

- Interdit : salle de sport, parquet, mur intérieur, miroir.
